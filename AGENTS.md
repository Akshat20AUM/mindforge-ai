# MindForge AI - Developer & AI Instructions

## 🧰 Tech Stack & Core Libraries
- **Framework:** Next.js 14 (App Router, React 18, Server Components)
- **Language:** TypeScript (Strict mode)
- **Styling:** Tailwind CSS
- **AI SDK:** Vercel AI SDK (`ai` + `@ai-sdk/groq`)
- **LLM Model:** Groq (`llama-3.3-70b-versatile`)
- **Validation:** Zod (Type coercion via `z.coerce`)
- **Deployment:** Vercel

---

## 🛠️ Common Commands

### Development
- `npm run dev` — Starts local dev server at http://localhost:3000

### Build & Verification
- `npm run build` — Production build check (verifies TypeScript & page compilation)
- `npx tsc --noEmit` — Type-checks project without building
- `npm run test` — Runs Vitest unit test suite

### Dependencies
- `npm install` — Installs project dependencies

---

## 📁 Architecture & Key Paths

- `src/app/api/generate/route.ts` — API route handler for AI study deck generation.
- `src/lib/ai-schema.ts` — Zod schemas (`DeckGenerationSchema`, `FlashcardSchema`, `QuizQuestionSchema`).
- `src/components/Flashcard.tsx` — Accessible flip card component.
- `src/components/Quiz.tsx` — 4-option interactive quiz component with scoring.
- `src/app/page.tsx` — Main application screen and form handler.

---

## ⚙️ Coding Rules & Conventions

1. **Imports:** Use path alias `@/` for imports (`@/lib/ai-schema`, `@/components/...`).
2. **AI Provider:** Always use `@ai-sdk/groq` with `llama-3.3-70b-versatile`. Key environment variable is `GROQ_API_KEY`.
3. **Structured AI Responses:** Always generate responses using `generateObject` passed into `DeckGenerationSchema`.
4. **Zod Schemas:** Use `z.coerce.number()` for numeric fields generated by LLMs to prevent type validation crashes.
5. **Accessibility (WCAG 2.1 AA):**
   - Interactive elements must support `Enter` and `Space` keyboard key handlers.
   - Dynamic content updates must use polite live regions (`aria-live="polite"`).
   - Component tab patterns must use proper W3C roles (`role="tablist"`, `role="tab"`, `role="tabpanel"`).
